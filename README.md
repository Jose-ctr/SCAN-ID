# SCAN-ID

## Lost Document Recovery Network Kenya

SCAN-ID is a secure Kenya-first network for recovering lost personal documents.

Report a lost document, report a found document, securely match the records, notify the verified owner by SMS, process the recovery payment through M-Pesa, and coordinate a safe handover.

### Supported Documents

- National ID
- Passport
- Driving Licence
- Student ID
- Staff / Work ID
- Bank / ATM Card
- Insurance Card
- Other personal documents

### Recovery Flow

**Lost → Found → Match → Notify → Verify → Pay → Handover → Recovered**

Document numbers are never publicly exposed. SCAN-ID stores protected document identifiers and uses secure recovery references for matching and handover.
